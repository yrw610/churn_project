# 信用卡客户流失预测项目
> 机器学习课程实验：基于客户信息预测信用卡客户是否流失

## 项目简介
本项目使用银行信用卡客户数据集，通过机器学习算法构建客户流失预测模型，挖掘影响客户流失的关键特征，辅助银行开展客户留存运营。

## 数据集
- 数据集：BankChurners
- 样本量：10127条，包含客户年龄、收入、交易次数、信用卡等级、是否流失等特征
- 任务：二分类（0=未流失，1=流失）

## 实验流程
1. 数据读取与探索性数据分析 EDA
2. 数据清洗、异常值处理、特征编码
3. 特征相关性分析、特征筛选
4. 数据集划分：训练集 / 测试集
5. 模型训练：逻辑回归、随机森林、XGBoost等
6. 模型评估：准确率、召回率、F1、AUC、混淆矩阵
7. 特征重要性分析，结论总结

## 实验结论
> 本次实验基于BankChurners信用卡客户数据，分别采用逻辑回归、随机森林、XGBoost构建客户流失预测模型。综合对比各项评估指标，XGBoost模型预测效果最优；客户总交易次数、信用卡使用额度变化、接触服务次数是影响客户流失的核心特征。银行可针对高风险客户制定挽留策略，降低客户流失率。
